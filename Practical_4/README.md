### Linux Commands I Learned

- pwd : Shows current directory
- ls : Lists files and folders
- cd foldername : Changes directory
- mkdir my_project : Creates a new folder
- touch notes.txt : Creates a new file
- cp file.txt backup/ : Copies files
- mv old.txt new.txt : Moves or renames files
- rm file.txt : Deletes a file
- rmdir foldername : Deletes an empty folder
- cat file.txt : Displays file content
- nano file.txt : Opens file editor
- chmod +x script.sh : Changes file permission
- sudo apt update : Runs command as administrator

- These commands helped me understand Linux navigation, file management, security, and system monitoring.
